# 🔢 Digit Recognition using Deep Learning

The **Digit Recognition** project is a deep learning-based application that identifies handwritten digits (0–9) using a trained neural network. Built using **Python** and implemented in **Jupyter Notebook**, this project demonstrates the use of machine learning for image classification tasks.

---

## 🧠 Model Overview

- Trained a **Convolutional Neural Network (CNN)** on the **MNIST** dataset.
- Achieved a test accuracy of **~98%**.
- Recognizes digits from 0 to 9 using grayscale image inputs (28x28 pixels).

---

## 🛠️ Tech Stack

- **Python**
- **Jupyter Notebook**
- **TensorFlow / Keras**
- **NumPy**
- **Matplotlib**

---

## ⚙️ Features

- Loads and processes the MNIST handwritten digit dataset  
- Builds and trains a CNN for digit classification  
- Evaluates model performance with accuracy and visualizations  
- Predicts digits from test images and displays results

---

## 🚀 How to Run

1. Clone the repository:
   git clone https://github.com/Mushkan3975/Digit_recognition_.git
   cd Digit_recognition_
   
2. Make sure you have the required libraries installed:
   pip install tensorflow numpy matplotlib
   
3. Open the notebook in Jupyter:
   jupyter notebook DigitRecognition.ipynb

 4.Run all cells to train the model and test predictions.
